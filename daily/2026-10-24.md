> 遇到的最大障碍（含完整报错）：
> ```
> CommandNotFoundError: Your shell has not been properly configured to use 'conda activate'.
> ```
> 在 PowerShell 里直接敲 `conda activate research` 报这个错；另外 `pip install torch` 下载到一半超时：
> ```
> ERROR: Exception: Traceback ... ReadTimeoutError: HTTPSConnectionPool ... Read timed out.
> ```
>
> 解决方式（自己查到的 / AI 给的 / 问人的）：
> - conda 报错：AI 给出原因（PowerShell 未初始化 conda），执行 `conda init powershell` 后重开终端解决；
>   也确认了可以直接用开始菜单的 Anaconda Prompt 绕过。
> - pip 超时：自己查到换国内镜像源，`pip install torch -i https://pypi.tuna.tsinghua.edu.cn/simple` 后 1 分钟装完。
>
> 验证方式（我怎么确认它真的解决了）：
> 1. 命令行前缀出现 `(research)`，说明虚拟环境已激活；
> 2. `python -c "import torch, numpy, pandas; print(torch.__version__)"` 正常输出版本号，没有报错；
> 3. Jupyter 里新建 Notebook，单元格能打印出结果，Kernel 显示 Python 3.10 (research)。
