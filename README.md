## 三、怎么更新这份文档

日常只需三步：

```bash
# 1. 记录今天学了什么
cp logs/模板.md logs/2026-10-28.md   # 然后填写内容

# 2. 更新进度数据（模块完成数、每日时长、里程碑）
#    编辑 data/progress.js

# 3. 提交并推送，网页会在 1 分钟左右自动更新
git add .
git commit -m "docs: 记录 2026-10-28 学习进度"
git push
```

| 我想改什么 | 改哪个文件 |
|-----------|-----------|
| 每天学了多久 | `data/progress.js` → `daily` |
| 模块完成进度 | `data/progress.js` → `modules` |
| 新增里程碑 / 时间线 | `data/progress.js` → `timeline` |
| 写详细学习笔记 | `logs/YYYY-MM-DD.md` |
| 改页面样式 | `assets/style.css` |

## 四、发布到 GitHub Pages（在线访问）

1. 在 GitHub 新建仓库 **`learning-progress`**（Public，不要勾 README）
2. 本地关联并推送：

   ```bash
   git remote add origin https://github.com/<你的用户名>/learning-progress.git
   git branch -M main
   git push -u origin main
   ```

3. 仓库 → **Settings → Pages → Build and deployment**，Source 选 **GitHub Actions**
4. 推一次代码，Actions 会自动部署，完成后访问：
   `https://<你的用户名>.github.io/learning-progress/`

> 工作流文件已在 `.github/workflows/deploy.yml`，不用自己写。
