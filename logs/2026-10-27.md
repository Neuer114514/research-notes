## 学习内容详情

### 1. 页面结构

先写骨架（`index.html`），再写样式（`assets/style.css`），最后写渲染逻辑
（`assets/app.js`）。所有内容都由 `data/progress.js` 里的数据生成，
以后只改数据文件就能更新页面。

### 2. 自动部署

```yaml
# .github/workflows/deploy.yml
on:
  push:
    branches: [main]
jobs:
  build:
    steps:
      - uses: actions/checkout@v4
      - uses: actions/upload-pages-artifact@v3
        with:
          path: .
  deploy:
    needs: build
    steps:
      - uses: actions/deploy-pages@v4
```

只要 push 到 main 分支，Actions 就会自动把站点发布出去，不用手动传文件。

### 3. 踩坑记录

一开始想把数据写成 `.json` 再用 `fetch` 读取，但本地用 `file://` 打开时
会被浏览器的跨域策略拦住。改成 `data/progress.js` 里直接赋值
`window.LEARNING_DATA`，用 `<script src>` 引入就好了。

## 遇到的问题与解决

| 问题 | 原因 | 解决办法 |
|------|------|---------|
| 本地打开页面一片空白 | `fetch` 加载 json 被 CORS 拦截 | 改用 JS 文件赋值全局变量 |
| SVG 进度环不显示进度 | `stroke-dasharray` 与半径不匹配 | 按 `2πr`（r=56 → 351.86）重新计算 |
| Actions 部署 404 | Pages 来源没切到 GitHub Actions | Settings → Pages → Source 改为 GitHub Actions |
