## 学习内容详情

### 1. 二分查找统一模板

```python
def binary_search(nums, target):
    left, right = 0, len(nums) - 1      # 闭区间 [left, right]
    while left <= right:
        mid = left + (right - left) // 2   # 防止溢出
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1
```

关键：`while` 条件和 `left/right` 的更新必须配套，混用就死循环。

### 2. 双指针的三种形态

| 形态 | 适用场景 | 例子 |
|------|---------|------|
| 左右指针 | 有序数组、反转 | 两数之和、反转字符串 |
| 快慢指针 | 链表、原地去重 | 判断环、删除重复项 |
| 滑动窗口 | 子串 / 子数组 | 最小覆盖子串、最长无重复子串 |

| 问题 | 原因 | 解决办法 |
|------|------|---------|
| 二分总是死循环 | 区间定义和边界更新不一致 | 固定用闭区间模板，`mid ± 1` |
